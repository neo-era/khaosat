📥 Nhập dữ liệu từ file Excel

Dòng có cột STT hợp lệ → cập nhật bản ghi đó. Dòng không có STT → thêm bản ghi mới. File cần hàng đầu tiên là tên cột đúng như Google Sheets (dùng file xuất từ Vùng E ở trên).

⚠️ Ảnh đính kèm không cập nhật qua import (giữ nguyên ảnh cũ). Kiểm tra kỹ dữ liệu trước khi xác nhận.
